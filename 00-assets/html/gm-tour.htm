Preparing is different from submitting

The website prepares text for Discord. Copying it does not send it. Post depth charts in the designated channel; follow commissioner instructions for camps; send offseason bid sheets by commissioner DM. In-season free-agent requests use the designated public channel.

The tour never clears or fills a tool for you. Edits you make in the real tools may remain in their saved drafts. Camps and bids can be learned at any time; only send requests when the applicable window is open.
